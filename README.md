# FAQ & Pengumuman Zeus2010

Situs statis tersedia di `index.html` dan diterbitkan melalui GitHub Pages saat ada push ke branch `main`.

URL situs: <https://jaka38577-pixel.github.io/ketentuandanFAQ/>

Di repositori GitHub, buka **Settings → Pages** dan pilih **GitHub Actions** sebagai sumber deployment. URL bawaan GitHub Pages tidak membutuhkan domain khusus atau konfigurasi DNS.

## Meminta pengindeksan mesin pencari

Tambahkan URL situs sebagai properti **URL prefix** di Google Search Console, verifikasi kepemilikan sesuai metode yang tersedia, lalu kirim `https://jaka38577-pixel.github.io/ketentuandanFAQ/sitemap.xml`. Mesin pencari menentukan sendiri kapan dan apakah halaman dimasukkan ke hasil pencarian; publikasi tidak menjamin pengindeksan atau peringkat tertentu.
